## 📖 Welcome to AdivaSetu

**AdivaSetu** (*Adivasi* + *Setu* / "The Bridge") is designed to make fellowship and scholarship governance straightforward, supportive, and accessible for everyone. 

Whether an applicant is pursuing a Ph.D. in India, preparing for Master’s studies at a top global university, or an officer is validating records, AdivaSetu brings every step into a single, cohesive system. 

Instead of dealing with confusing paperwork, multi-month waiting periods, and rejections over minor certificate discrepancies, AdivaSetu guides applicants gently through each stage, catches potential issues early, and ensures that financial support reaches scholars on time.

## 🧭 Who Is AdivaSetu Built For?

AdivaSetu serves all stakeholders involved in higher education fellowships:

```
┌────────────────┐     ┌────────────────┐     ┌────────────────┐     ┌────────────────┐
│   Applicants   │ ──► │  Universities  │ ──► │ Ministry Desk  │ ──► │  Direct Benefit │

└────────────────┘     └────────────────┘     └────────────────┘     └────────────────┘
```

1. **Students & Researchers**: Find eligible fellowship opportunities, apply with an adaptive form, receive real-time document validation feedback, and monitor stipend disbursements.
2. **University Nodal Officers / Registrars**: Verify bona fide university enrollment, supervisor allocations, and campus attendance without paperwork.

4. **Merit Screening Committees**: Conduct objective, multi-criteria evaluations using customizable merit formulas and transparent scoring.
5. **Sanctioning Authorities**: Issue official approvals, digitally sign sanction orders, and track fund disbursements directly into Aadhaar-seeded bank accounts.

## 🚀 Key Features & How It Works

### 1. Interactive Scheme Explorer & Eligibility Guide
* **How It Works**: Before starting an application, students can use the built-in Eligibility Guide to enter basic details—such as education level, intended study destination (India vs Abroad), and academic marks.
* **Instant Clarification**: The system checks these parameters against statutory criteria and indicates which schemes match the scholar's profile, explaining criteria clearly so applicants never feel lost.

---

### 2. Adaptive Application Wizard
* **How It Works**: Rather than forcing every applicant through a rigid, generic form, the application form automatically adapts based on the selected scheme.
* **Smart Contextual Fields**:
  * **When applying for NOS (Overseas)**: The form requests foreign university details, host country (UK, US, Canada, Germany, etc.), QS World University Rank, passport number, and language exam scores (IELTS/TOEFL).
  * **When applying for NFST (Domestic Ph.D.)**: The form adjusts to capture the Indian host institution, Ph.D. research topic/synopsis, supervisor details, and departmental bonafide status.
* **Autosave & Step-by-Step Progress**: Applicants can save their progress at any stage and return whenever they are ready without losing data.

---

### 3. Intelligent Document Assistant & Instant Pre-Check
* **How It Works**: When a certificate or document is uploaded, AdivaSetu’s document assistant performs an instant scan before submission.
* **What It Checks**:
  * **Name Consistency**: Checks that the name on the degree marksheet, Aadhaar card, and caste certificate align with the applicant profile.
  * **Financial Year Validity**: Confirms the income certificate corresponds to the required financial year (e.g. FY 2025–26).
  * **Scheme Ceiling Compliance**: Verifies declared annual income against the statutory scheme ceiling (e.g. ensuring NOS applicants are within the ₹8,00,000 threshold).
  * **Readability & Seal Presence**: Ensures uploaded scans are clear, legible, and contain authentic issuing seals.
* **Empowering the Applicant**: If an expired certificate or low-resolution image is uploaded, the applicant is politely notified right away with helpful suggestions on what to upload instead.

---

### 4. Zero-Rejection Deficiency Resolution Center
* **How It Works**: In traditional workflows, a minor mistake—like an unclear seal or an outdated document—often leads to outright rejection or months of delay. 
* **The AdivaSetu Solution**: If an officer notes an issue during review, a deficiency notice is created. The applicant receives an alert with specific instructions, and can simply upload a corrected document directly through their portal. Their place in the evaluation queue is preserved.

---

### 5. Officer Scrutiny & Human-in-the-Loop Governance
* **How It Works**: For reviewers at the Ministry and universities, AdivaSetu provides an intuitive review workspace.
* **Key Capabilities**:
  * **Side-by-Side Document Inspection**: Review uploaded certificates alongside extracted fields, with image zoom and rotation tools.
  * **AI Decision Support**: The system highlights verified fields and flags points that require human attention, while preserving sovereign officer authority—the decision to approve, ask for clarification, or flag a deficiency is always made by an authorized official.
  * **Full Audit Trail**: Every review step, note, and decision is logged with timestamps for transparency and accountability.

---

### 6. Transparent Merit Screening & Dynamic Rankings
* **How It Works**: For competitive fellowships, the screening committee can evaluate applications based on balanced, objective parameters.
* **Explainable Scoring**:
  $$\text{Composite Merit Score} = (w_1 \cdot \text{Academic Marks}) + (w_2 \cdot \text{Institute/QS Rank}) + (w_3 \cdot \text{Research Evaluation}) + (w_4 \cdot \text{Socio-economic Need})$$
* **Customizable by Policy**: Authorized administrators can adjust weighting criteria dynamically (e.g., placing more weight on QS rank for overseas studies) through the Scheme Configuration console without requiring code changes.

---

### 7. Post-Award Fellowship Lifecycle & DBT Tracking
* **How It Works**: AdivaSetu doesn’t stop at the selection letter; it manages the scholar’s ongoing fellowship journey.
* **Scholar Onboarding (Joining Report)**: Selected scholars can submit their official joining date, supervisor endorsement, and university joining report digitally.
* **Continuation & Annual Reviews**: Tracks multi-year progress reports and Research Advisory Committee (RAC) recommendations for seamless annual extensions.
* **Direct Benefit Transfer (DBT) Schedule**: Provides scholars with a clear schedule of their monthly stipends, annual contingency grants, and PFMS payment reference codes, with confirmation of Aadhaar-bank account seeding.

## 💻 Technical Architecture & Tech Stack

AdivaSetu is built on a resilient, modern stack designed for speed, accessibility, and offline continuity:

* **Frontend**: React 19, TypeScript, Vite 6, Tailwind CSS v4, Lucide Icons, Canvas Confetti.
* **State & Local Persistence**: Context API backed by dual-layer persistence (IndexedDB / LocalStorage fallback via `browserDb`), allowing the platform to run offline or in low-connectivity areas.
* **Backend API**: Node.js, Express 5, TypeScript (`tsx`), CORS, Dotenv.
* **Database & Search**: MongoDB Atlas (Mongoose ODM, replica sets, connection pooling).
* **Document Vault**: Supabase Cloud Storage (secure bucket storage with public CDN URLs for verified documents).
* **Hosting**: Express API deployed on Render; Frontend Single Page App deployed on Vercel with automated edge reverse-proxying.

## 🛠️ Getting Started Locally

### Prerequisites
* **Node.js**: v20 or higher
* **Git**: Installed on your system

### 1. Clone the Repository
```bash
git clone https://github.com/PuneetKumar1790/AdivaSetu.git
cd AdivaSetu
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory:
```env
PORT=5000
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.oq6h0ge.mongodb.net/adivasetu?retryWrites=true&w=majority
SUPABASE_URL=https://<project-id>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_supabase_secret_key
VITE_SUPABASE_URL=https://<project-id>.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_API_BASE_URL=http://localhost:5000
```
*(Note: If MongoDB Atlas or Supabase credentials are not provided, AdivaSetu automatically uses its built-in browser database fallback so all features remain functional out of the box).*

### 4. Run the Platform

**Start the Backend Server:**
```bash
npm run server
# API will start on http://localhost:5000
```

**Start the Frontend (in a separate terminal):**
```bash
npm run dev
# Application will launch on http://localhost:5173
```
